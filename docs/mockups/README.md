# UI Mockups

The Next.js frontend implements all required screens from Activity 1:

- User Registration (`/register`)
- Login (`/login`)
- Dashboard (`/dashboard`)
- Fire Extinguisher Management (`/extinguishers`, `/extinguishers/new`, `/extinguishers/[id]`)
- Inspection Scheduling (`/inspections`)
- Reports (`/reports`)
- Profile (`/profile`)
- Admin Users (`/admin/users`)

Run `npm run dev` in `frontend/` and capture screenshots for submission, or recreate in Figma using the same layout and labels.
